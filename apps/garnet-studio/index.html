Velocity Editor — live check

Type or paste Garnet source. After you stop typing, Studio runs garnet check --format json on the buffer (no execution) and renders the language's own diagnostics — capability coverage, bounds, parse errors. The buffer is ephemeral: nothing is sealed until you click Check or Run above.
