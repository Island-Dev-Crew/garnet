Understanding

State of the union

Two distinct Studio apps share one trust spine. Windows is far ahead on the cockpit; the Mac is ahead on native craft and as the canonical proof host. The job is to close the cockpit gap without regressing the Mac's strengths or blurring a single enforcement claim.

Methodology

The loop, and the loops within it

Every slice is a single, narrow, evidence-backed change confined to apps/garnet-studio-macos (+ its repo-root scripts/ contract). The outer loop iterates phases M0→M8; the inner loop per phase is the same six steps; the 7-pass review is itself a fan-out of seven dimensions × (Judge + Auditor).

01

Red tests first

XCTest cases that fail until the slice lands; contract-gate additions ride along.

02

Implement

A typed Codable decoder + a pure projection function a thin SwiftUI View only lays out.

03

7-pass review

External orchestration: 7 dimensions × Judge+Auditor, adversarially verified against the code.

04

Fix + ladder

swift build · swift test · the two python gates · the --self-test smoke.

05

Focused PR

Branch from fresh origin/main → push to fork → PR fork → origin, dogfood body.

06

Green CI → merge

Autonomous merge on IDC only once the new macOS CI job is green-and-required; else Jon-merge.

The 7 review dimensions (run by the external orchestration workflow, not self-run by the slice agent): correctness · honesty / overclaim · completeness · sequencing / feasibility · scope / integrity · executability · hidden risk. Each is Judged then independently Audited; the Auditor refutes false positives (this very plan had one — see the diff-caps note in M2).

The spine

Calibrated honesty — the rails that don't bend

"Evidence beats adjectives; premium is a score, not a vibe." The Mac plan renders the CLI's verdict verbatim and never invents capability. These are the sharpest overclaim risks the dossier guards.

Enforced
@caps + @max_depth — deterministic traps proven by test, both backends. seccomp applied on Linux only.
Declared
@bounded, memory, time, @mailbox — named-deferred; declared in source, no runtime trap.
Deferred
macOS App Sandbox / sandbox-exec + Windows AppContainer — named-deferred. macOS sandbox is architecturally exclusive with the spawn-the-CLI design (it would block every StudioProcessRunner spawn and the Velocity scratch write) — not a flippable toggle.
Sharpest risk
Never blur language/runtime-trap parity (Win/Mac/Linux) with OS-sandbox enforcement. Only native-Linux seccomp is applied; macOS + Windows are deferred. The Agent-Loop Console renders the decision.md scope fence byte-for-byte to preserve this.
Signing
Three distinct artifacts must never be conflated: GPG-signed CLI tarballs (real) · CycloneDX SBOM (deferred) · the Studio .app (adhoc, not Developer-ID, not notarized — blocked-external on identity).

Preserve — do not regress

  • Canonical ultrapunch accept/reject host + 6/6 S105 domain proofs
  • Native affordances: NSWindow sequencing, Settings scene, @AppStorage, help tags, ⌘1–5
  • The Converter/advisory lane (7 actions) + MIT cluster (4) + Continuation Pulse
  • All 10 Studio-suite rows (Rows 1–9 + the Boundaries block)

Deferred / Jon-owned — named, not built

  • macOS App-Sandbox enforcement (sandbox-exec / seatbelt)
  • Developer-ID signing + real notarytool submission (blocked-external)
  • cotypist / LSP Studio surface (post-RB-3/RB-7; AGENTS.md amendment + security review)
  • Studio MCP server / agent-legibility workstream (post-RB-3)
  • The release tag stays Jon's — no autonomous tag

Loop ⇄ Integrity-Rule-1, resolved once. A slice may add contract-test assertions that only tighten coverage in its own PR — but any gate-version bump, loosening, CI-workflow change, signing/secrets change, or cross-OS-ledger edit is a separate human-merged PR that lands first. Integrity Rule 1 explicitly names scripts/test_garnet_macos_studio_shell.py and GARNET_CROSS_OS_REPRODUCIBILITY.md as human-merge-only. Autonomous merge is the repo-wide discipline (handoff §Branching & Merge Discipline + CLAUDE.md's four integrity rules) under those carve-outs — not a borrowed Windows grant.
