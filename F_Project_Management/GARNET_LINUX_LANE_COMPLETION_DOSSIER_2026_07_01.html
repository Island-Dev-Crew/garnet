The three native proofs

L1 · seccomp generated-policy applied + trapped PROVEN

tools/seccomp-apply/prove.sh re-run against a fresh build of current main. @caps(fs) → socket() BLOCKED (EPERM), deterministic over 3 runs; @caps(fs,net) → socket() ALLOWED (policy-driven). garnet sandbox stays generation-only (enforced:false); this proves the GENERATED policy is applied + traps on a real kernel via the reference harness. Gate: garnet_seccomp_apply_status.py --gate.

L2 · CLI native .deb clean-install PASS

cargo deb → garnet_0.8.1-1_arm64.deb → dpkg -i → /usr/bin/garnet. The installed binary: version 0.8.1; clean program check+run exit 0; undeclared fs use flagged at check time (check.caps_coverage) AND trapped at runtime (capability: fs::read_file requires @caps(fs)) — the enforced @caps kernel on a natively-installed system package. Gate: garnet_native_debian_cli_install_status.py --gate.

L3 · Tauri Studio native build + install + launch PASS

tauri build --bundles deb (Tauri v2) → Garnet Studio_0.8.1_arm64.deb → dpkg -i → /usr/bin/garnet-studio (+ a .desktop entry). --studio-smoke passes (status=passed, platform=linux, cli_found=/usr/bin/garnet, provider_api_called=false); the GUI launches headless under xvfb and runs 20s without crashing (exit 124 = timeout). Closes the gap the WSL/WSLg smokes disclaim. Gate: garnet_native_linux_studio_status.py --gate.
