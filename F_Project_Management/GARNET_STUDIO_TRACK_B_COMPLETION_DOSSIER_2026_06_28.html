The seven multi-pass catches

Bugs and wrong turns caught and resolved across the arc — the value of the gate + the build-then-verify discipline.

1 · The CI "mystery crash" was an unbounded loop → OOM root-caused

M2's macOS Studio gate hung ~4.6 min then was OOM-killed (26.6 GB footprint). macOS sample of the live xctest pid pinned it to AgenticDogfoodScriptLocator.ancestorRoots() spinning in URL.deletingLastPathComponent().

Cause: the walk broke only on a fixed point; on macOS 15 / Darwin 24 (the CI runner) URL("/").deletingLastPathComponent() never converges — it prepends ../ forever. Local macOS 26 converges, so it passed locally.

Fix: bounded the loop (stop at root / fixed point / parent-not-shorter + hard cap) across all 12 identical locator copies + a regression test.

2 · Wrong hypothesis: the executable-test-host reverted

Before the OOM was found, M2 split the app into a library + thin @main executable on the theory that @testable import of an executable hosted @main in the test process. It compiled clean but did not fix the hang.

Reverted: the source move broke 35 hardcoded Sources/GarnetStudio/ path references across packaging contracts, promo-video probes, and docs (caught by the agentic dogfood matrix). The real fix was independent.

3 · Swift-6 main-actor isolation, enforced harder on CI fixed

The library-split launcher called App.main() (main-actor-isolated) from a nonisolated function. Local 6.3.2 inferred it; the CI toolchain rejected it. (Subsumed by the revert, but the lesson stands: build with -strict-concurrency=complete locally.)

4 · M1 swift-testing + XCTest dual-runner crash fixed

A Swift test referencing a @MainActor View entangled the package's dual test runners and aborted the process on CI.

Fix: keep Swift tests over PURE nonisolated projection types only; guard View wiring via the python source-contract. Adopted as the rule for M2–M7.

5 · Buffered CI logs hid the hang point tooling

NSUnbufferedIO did not help — the pipe to the GitHub log is block-buffered and flushes only at process exit, so the last-flushed line ≠ the hang point.

Fix: a sleep-then-sample watchdog on the live pid is the way to locate a CI-only hang. (Used to crack catch #1.)

6 · M5 contract pointed at the wrong file fixed

The agent-loop contract asserted the record-dir artifact filenames against the pure bridge, but those literals live in the disk reader (AgentLoopCommand).

Fix: split the assertions — gates/honesty on the bridge, artifact filenames on the command.

7 · A contract that contradicted its own honest copy fixed

M7's contract forbade the substring distribution-ready — but the Gatekeeper row honestly says "Not distribution-ready."

Fix: dropped the crude substring guard; the headline test already proves no readiness over-claim.
