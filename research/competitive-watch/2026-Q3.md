**Bounded comparison with Garnet**

- **Agent proposals.** `garnet agent-loop` gates a proposal on `diff-caps`, a trapping run and a seal, and it runs the proposal on the host with no OS sandbox. SEMAPRAX separates proposal from authorization and is pre-alpha. No page read claimed OS-level sandboxing for a language here.

## What this changes for Garnet

- **Differentiation.** Transitive capability checking is shared with at least four peer languages. The distinct pieces this quarter's sources did not show elsewhere are the program-wide declared-surface diff (`diff-caps`) and its use as an acceptance gate.
