PLANNED · NOT YET AVAILABLE

The Garnet Playground is on the roadmap.

An in-browser playground — compile and run Garnet from the page via a WebAssembly build of the toolchain — is planned but not built yet. We are not shipping a fake editor: when it works, it will appear here, and not before.

Until then, the real first-project loop takes about a minute locally:

curl --proto '=https' --tlsv1.2 -sSf https://garnet-lang.org/install.sh | sh
