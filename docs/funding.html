Funding

Plainly: Garnet is a pre-revenue, single-maintainer project under Island Development Crew. No grants, sponsors, or donors fund it today. This page exists so the support options are real and the absence of others is stated, not implied.

Support the work

Ko-fi — one-off or recurring tips go directly to the maintainer: ko-fi.com/jonisaac. This is the only live funding channel right now.

GitHub Sponsors — planned, not yet set up. It is listed here so the roadmap is honest; there is no Sponsors page to link until it exists.

Stars & contributions — starring and contributing to the repository is, realistically, the most valuable non-financial support at this stage.

Commercial & sponsorship inquiries

For commercial support, integration help, or sponsorship discussions, use the contact path in SECURITY.md (it carries the maintainer's real contact) or open a GitHub issue. There is no dedicated sales address to publish, and a fabricated one would be worse than none.

Where money would go

Honestly: maintainer time. Garnet is research-grade and the binding constraint is engineering hours toward the open lanes (signed installers, native backend, proof and empirical work) — not infrastructure cost. No promises are attached to any contribution.
